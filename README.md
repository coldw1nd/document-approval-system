# Сервис электронных заявлений

Веб-приложение для просмотра электронных заявлений, их статусов, документов, комментариев и пользователей. Проект продолжает ПР1–ПР7: SQL-база SQLite сохраняется как исходный слой, в ПР9 добавлены Django ORM-модели и перенос в `db.sqlite3`, в ПР10 настроены административная панель, ORM-инструменты, статусы и отладка SQL-запросов.

## Возможности

- список заявлений с поиском по названию, описанию, заявителю и комментариям;
- фильтрация по статусу, сортировка и пагинация с сохранением GET-параметров;
- карточка заявления с документами и комментариями;
- список пользователей и документов;
- статистика заявлений по статусам;
- Django Admin с поиском, фильтрами, сортировкой, inline-записями, массовым действием и управлением правами;
- менеджер QuerySet с выборками по статусам;
- вычисляемое поле длины описания и slug-ссылки;
- контекстный процессор для общего шаблона;
- Django Debug Toolbar для локального анализа SQL.

## Модели и связи

- `users.User` — пользователь;
- `applications.Status` — статус с кодами `TextChoices`;
- `applications.Application` — заявление;
- `documents.Document` — документ заявления;
- `applications.Comment` — комментарий к заявлению.

Пользователь имеет несколько заявлений и комментариев; статус используется несколькими заявлениями; заявление содержит документы и комментарии. Внешние ключи `PROTECT` сохраняют историю заявлений и пользователей, а вложенные документы и комментарии удаляются вместе с заявлением.

## Базы данных

- `data/applications.sqlite3` — исходная SQL-база ПР7;
- `db.sqlite3` — целевая база Django ORM.

Исходная база ПР7 `data/applications.sqlite3` уже включена в проект и используется только как источник переноса. Целевая база Django ORM — `db.sqlite3`. Для восстановления исходной базы из JSON выполните `python db/import_json.py`; команда пересоздаёт исходную SQL-базу и сбрасывает изменения, внесённые непосредственно в неё.

## Установка и запуск

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python db/import_sqlite_to_orm.py
python manage.py createsuperuser
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`, административная панель доступна по `/admin/`. Django Debug Toolbar отображается только в локальном режиме `DEBUG=True`, если пакет установлен.

## Проверка

```powershell
python manage.py check
python manage.py makemigrations --check
python manage.py showmigrations
pytest -v
flake8 . --extend-exclude=.venv,venv,env,__pycache__,migrations
```

Для анализа SQL откройте страницу списка заявлений и раздел SQL в Django Debug Toolbar. Проверяйте запросы списка, поиска, фильтрации и пагинации, а также загрузку связанных моделей.
